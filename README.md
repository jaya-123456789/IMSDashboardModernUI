# IMS Dashboard Modern UI Revamp

Modern ERP dashboard UI revamp developed using ASP.NET MVC (.NET Framework).

## Features

- Engineer Dashboard
- KPI Cards
- Advanced Search Filters
- Recent Service Orders
- Job Details Workflow
- Certificate Management UI
- Modern Responsive Layout
- Bootstrap & Font Awesome UI

## Modules Included

### 1. Dashboard
- Open / Closed / Partially Submitted KPI cards
- Search & filter section
- Recent service orders table
- Through SO links to Job Details screen
### 2. Job Details -Transaction
- Job Header- SO Details
- Job Details- Accept / Reject workflow
- Job Certificate tabs - Add / Delete / Submit certificates and Certificate filters
## Technology Used
- ASP.NET MVC (.NET Framework)
- Bootstrap 5
- HTML / CSS / JavaScript
- Font Awesome

## Note

This project is developed as a UI/UX revamp prototype with mock/demo data.
